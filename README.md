# Arena simulation studies

This repository collects three course projects I used to learn discrete-event simulation in Arena. They are small studies rather than production models, but they helped me practice turning a process description into queues, resources, and measurable outcomes.

## Included studies

### Emergency department

The model follows patients through an emergency-department process and tests resource configurations. The accompanying Process Analyzer files were used to compare scenarios rather than to make a clinical recommendation.

### Operating room

This study looks at operating-room flow over longer simulation runs. The included image is a saved result view from a 100-day run.

### Flow shop

The flow-shop model explores how jobs move through a sequence of workstations. The saved runs show how changes in the setup affect queues and utilization.

## Files

- `.doe` — Arena models.
- `.pan` — Process Analyzer scenarios.
- `.png` — selected result views.
- `FlowShop_Report.docx` — the original course report for the flow-shop model.

Arena is required to open and run the model files. Generated databases and temporary output files are intentionally not included.

## Scope

These models were created for learning and comparison. They simplify real systems and should not be treated as validated operational or clinical tools.
